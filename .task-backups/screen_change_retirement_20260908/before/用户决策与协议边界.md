## 1. 用户批准的方向与取舍

产品是跨 App、跨措辞、可扩展到多手机的通用视觉操作 Agent。现有通用动作能组合完成的新任务无需改代码；不得建立固定 App 流程、截图坐标补丁或任务关键词分支。轻量 DDD 模块化单体只划分职责，不增加运行裁决。

用户已批准单 Qwen 整任务循环：Qwen 消费原始整任务、本次会话实际动作/结果历史和新截图，在同次响应中报告画面事实并选择一个动作，或报告整任务 finish。本地执行一次后重新取图。不保留 DeepSeek 首次规划、子目标固定推进、预先效果清单或隐藏计划。
普通任务是否遗漏步骤、是否完成的语义判断交给 Qwen；本地不再独立证明任务完整性。用户已接受该取舍，但不等于已证明模型不会误判或真机任务已经成功。

用户于2026-09-07明确选择使用 Open-AutoGLM 的完成方法，取代随后讨论的本地完成清单方案：只传本轮当前截图，保留原任务和本会话实际执行的完整文字历史，由 Qwen 选择 action 或 finish；删除上一动作前图的缓存、参数和请求入口，不保留兼容开关。本地不新增发送回执清单或独立任务完整性裁决。适配保留当前稳定帧组以识别闪烁光标（不是旧图），保留实际 canonical/transport/视觉结果文字历史，而不把未执行的模型想法当事实。异常仍报告错误，不照搬异常转 finish。该循环机制有条件可行，能否改善本项目误完成尚未验证；用户已获知上游没有独立防误完成保证。

借鉴 Open-AutoGLM 的通用小循环，不复制任意 ADB 导航、输入前隐式清空或异常转成功。

- Qwen 决策：`2026-09-06-qwen-whole-task-v19`。
- 单步观察：`2026-09-07-single-step-current-frame-v22`。
- 当前设备动作集合在观察前一次签发，观察、绑定和执行消费同一份。独占动作只来自显式 API/能力试验参数，不从普通自然语言任务猜出。
- 模型普通输出为 action 或 finish，不拥有额外语义 blocked 权限。matched 不是整任务成功；当前图 Qwen finish 是唯一语义完成权威。
- 当前响应与截图同帧绑定；不复用旧坐标、旧 decision 或旧 scope。实际历史不混入未执行计划，也不带入其他会话。
- 单步使用扁平 nullable schema；不适用的 text/app/previous_action_outcome 等字段为 null。唯一 canonical 解析器检查字段组合，不建立第二动作选择器。

## 4. 单一视觉与几何权威

点按类唯一目标为同帧 decision.target 的 role/meaning，label/evidence 可选；唯一落点是 tap_point。目标不携带第二套 bounds/states 几何；额外 scene.elements 在入口排除，仅保留原始诊断。不得从元素中心、OCR、颜色或本地分割改点或另发否决。
非点按元素手势继续绑定当前元素几何；轨迹须有限非零、有唯一主方向且屏幕内，起点属于当前目标。删除 2% 边缘、8% 最短/90% 最长和比例内缩等经验门，保留真实标定和硬件包络。
confidence 和可选页面事实只作诊断，不形成第二动作否决。2026-09-08 用户在离线误拦复现后接受：删除动作前模型观察帧与确认帧的整图差异否决，以及机械执行门的整图亮度/结构差否决，不保留阈值开关或旧拒绝入口。用户接受模型思考期间真正跳页、按钮移动或同尺寸取景改变可能漏拦并错误执行一次的风险；动作后新图不能撤销已有外部效果。
真实截图采集、多帧稳定/清晰度、尺寸一致、设备/当前观察 scope 和一次性凭据、合法坐标/机械可达、输入结果及动作后效果变化保护继续保留。fingerprint 只绑定产生动作的观察及授权归属，不证明两次截图像素相同；结果不得把已删除的像素身份检查记录为通过。不得以放大阈值、固定区域/OCR/颜色改点、额外模型复核或 App 特例替代已删除门禁。

## 5. 输入与唯一文字通道

- 同帧 input_structure 的 text、preedit_text、focused 与字段边界是唯一输入事实；scene 不重复裁决正文或输入 ID。内部 current_input 身份由唯一投影生成，不让模型猜本地编号。
- focused 只原样消费 true/false/null。模型综合稳定帧独立认定事实，不从任务或想选动作倒推；本地不凭键盘可见、历史点击、光标关键词或像素算法补焦点。
- 非空文字动作前须同帧 focused=true；未知时由 Qwen 选择聚焦动作，再取新图。空清空可按当前字段已空判断，无须先执行空广播。清空后核对正文和预编辑为空，不要求持续聚焦；后续输入独立核对新图焦点。
- 自然任务的完整预期输入文字由 Qwen 本次动作提供；显式 API 正文还必须逐字一致。已提交正文和预编辑分开；不截断、不 NFC 改写。既有前缀只追加差额，非前缀必须另选清空，不能隐式清空再输入。
- ADB Keyboard 是唯一文字 transport：固定可信可执行文件、设备 serial、IME 与 ADB_INPUT_B64 / ADB_CLEAR_TEXT 广播。press_enter 绑定同帧多行字段，以固定文字广播追加换行，不选择键盘键、不新增 keyevent。
- 机械文字、拼音/候选、键盘 OCR、Companion IME Android/bridge/配对/editor session 全部退役，无兼容或回退。禁止卖家文字框、剪贴板、Accessibility、任意 ADB/Shell 参数。
- 广播成功只证明 transport 回执，仍需动作后新图核对输入结果。原始模型响应脱敏保存早于解析，诊断不影响执行。

## 6. 系统动作与后台清理

launch_app 仅使用本地批准注册表的语义别名和固定 launch reference，不开放包名/Shell/Intent/组件命令。动作后不恢复包名、标题或导航栏字段的第二完成裁决。

2026-09-08用户进一步批准放宽过严协议：launch_app、home、back、open_recent_apps、reveal_system_navigation、wait_for_change附带的纯decision.target描述只留原始诊断，在唯一canonical解析入口排除。描述对象仅允许role/meaning/label/诊断element_id的字符串或null，以及evidence的字符串列表或null；作为非执行说明，不要求描述字段齐全。不得包含几何、命令、嵌套动作或其他执行载荷。app仍是唯一应用选择来源并须解析到可信注册表；系统动作只按canonical类型执行，不从描述生成点击、输入或风险判断。顶层坐标、轨迹、元素引用、正文及多动作冲突检查保留；不扩展到点按、文字或finish。模型生成仍要求无关字段为null，提示词/schema不变。输入、清空、换行统一忽略模型冗余element_id，只消费同帧input_structure投影的当前字段；聚焦、多行、正文、设备及一次执行规则不变。状态接口删除过时12/24局部上限及普通外部效果确认次数说明，真实整任务预算仍由原有唯一预算字段公开。

2026-09-07用户明确确认有限本地导航例外：正式会话选择 `open_recent_apps` 后，本地负责“非主屏幕先 Home → 当前新图确认 Launcher → 打开最近任务 → 新图交回 Qwen”。这适用于所有打开后台动作，不再仅限清理；当前图已经是 Launcher 时无需多按 Home。只按 canonical 动作触发，不扫描自然任务关键词。此例外取代原先完全依赖 Qwen 遵守导航顺序的规则，不恢复其他子目标编排或本地整任务完成清单。
本地导航期间不能用模型的其他动作或 finish 跳过待执行导航；主屏幕事实仍来自同次新图 scene.foreground_app_id=launcher，不从历史点击、App 包名或本地视觉推导。未到主屏幕时在整任务预算内按新图纠正 Home；每次只执行一个物理动作，重新取图并签发 scope。暂停保留导航进度，恢复重新观察；真实能力缺失/观察/设备故障照实报告。显式 open_recent_apps 能力范围包含其 Home 前置动作，在观察前一次签发；其他显式动作范围不变。底层设备原语仍一次只做一个动作。
模型原始建议、本地导航来源和实际动作分别记录；历史只记真实执行。该例外保证已选打开后台动作的顺序，不保证模型不会漏选打开后台或误认画面。打开后台后的目标查找、切换、清理及整任务完成交回 Qwen。
清理后台（全部或指定 App）仍须从新图确认后台后，绑定唯一可见系统清理按钮点击。需要寻找时允许按新图滚动，不再滑动任务卡片清理；用户允许同时清除其他可清理后台。清理按钮规则不扩展到普通查看/切换，不建立本地清理意图判断。

## 7. 容量、预算与错误

2026-09-07用户批准接口收敛：普通手动暂停保留会话与设备归属，停止于当前一次动作及其结果记录之后；废弃旧动作/风险授权。恢复必须重新观察并签发新scope，不重用旧坐标、不清零预算；取消或真实终态释放设备。预算暂停同样须出现在活动会话查询中。能力验收结束单独释放会话，不借普通暂停终止。scope与可晋级能力映射只使用正式定义；能力验收消费真实执行结果及当前新图，不再索要已退役的Controller业务进度证明。该批准不恢复本地完成清单、不修改Qwen提示或额外调用模型。

删除任务、正文、字段/收件人数量、上下文深度的人为容量上限；删除观察元素数量和固定表达要求。实际模型上下文、UTF-8、内存/系统资源错误如实报告。
用户已接受默认每任务 100 次设备动作、200 次观察申请，网页可调，跨请求累计；修改限额或新 scope 不清零。预算耗尽暂停保留进度，不记成功；动作前预留动作后观察额度。观察尝试与实际模型联网次数分别记账。
导航、聚焦、滑动纠正只用新图/新 scope 并受整任务预算约束，无局部分项次数门；不确定效果不自动重做。
