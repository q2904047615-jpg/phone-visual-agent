### 状态含义

- **已验证可行／保留**：约束与明确产品合同或确定性执行身份一致；只表示该保护目的及所列离线行为，不表示真机任务通过。
- **有条件可行／限域保留**：仅在写明的动作、transport 或维护入口内成立；外溢到普通任务不成立。
- **尚未验证／需要证据**：有工程目的，但具体阈值、覆盖范围或必要性尚无足够证据。
- **不建议／建议调整**：已识别与当前用户合同冲突，或该门不能证明它声称的事情。这里只登记，不修改生产行为。

## 审查边界

静态范围是全部 `poc/agent/**/*.py`、正式模型提示词、`poc/web_app.py`、官方客户端/CLI、`poc/static` 中的 JS 和 HTML。包括仍有效的能力验收等非当前常用分支；机械文字、拼音和键盘OCR链已物理删除。包初始化也记录哈希，没有限制候选的文件仍出现在清单中。

不把 `poc/test*`、历史输出、experiments、旧分支、Git 归档、第三方依赖实现及用户本地含密钥配置当成正式限制来源。测试按需用于核对必要性；本次未加载服务、修改配置、联网调用模型或执行手机动作。CSS 不产生动作授权，未进入行为索引。第三方库内部限制、操作系统/手机行为不在“全部本项目源码限制”的声称范围内。

索引保守包含全部 Python 条件分支、返回、显式拒绝、过滤、schema 和上限调用，以及完整网页/提示词非空行；其中有大量普通分派、可选事实撤销、显示/诊断和异常透传，**不是每一行都算产品阻断**。索引中的审查族是人工阅读入口，不是自动批准结果。静态覆盖不证明动态可达性，也不证明所有组合无冲突。

- 验证：8000字自然任务请求、6000字正文和40字段/收件人离线通过；未调用实际模型或手机。

### R04 JSON、版本、字段与枚举合同

- 条件/位置：`dashscope_vision_provider._extract_json_object`、`canonical_action_protocol.normalize_model_step_decision`、观察 envelope、各值对象；拒绝重复 JSON 键、歧义多对象、未知动作、动作参数冲突和旧协议。
- 必要性：一份响应只能导出一个意思明确的动作；重复键可能令不同解析器消费不同值。纯语法唯一归一化与固定版本是已批准合同。
- 影响：合法意图也可能因格式错误无法执行；这是模型合同/接口问题，不是手机失败。中性额外诊断、可选 confidence、未使用 states 应被忽略或归一化，不能硬拒绝。
- 结论：唯一语义**保留**；精确目标字段集合是当前明确合同，不因本审查静默放宽。不能把所有 `extra=forbid` 一概解释成必要，须区分本地请求、目标身份与可选视觉事实。
- 验证：扁平 schema 全动作、重复键/第二动作拒绝、单对象数组归一化、可选诊断缺失；`test_flat_observation_contract.py`、`test_point_scene_projection.py`。

### R05 动作全集、能力集合与一次签发

- 条件/位置：`canonical_action_kinds`、`action_capabilities`、`_prepare_observation_actions`、canonical binder；只接受当前集合内一种动作。缺少可信 launch 映射时只排除 `launch_app`。
- 必要性：模型不能选择不存在的 transport 或突破用户明确指定动作；观察、绑定、执行必须消费同一份不可变集合。
- 影响：设备能力配置少报或 required_action_kind 误写会限制任务，即使物理上能做。此时要修正确来源，不能模型响应后二次裁剪或自动改动作。
- 结论：单一集合**保留**；设备“未验收”与“实际不支持”分开，见 R30。普通描述不得被本地关键词猜成独占动作。
- 验证：`test_current_frame_action_scope.py`；先未聚焦→聚焦→清空，与初始已聚焦→直接清空两种组合。

### R06 点按唯一身份和唯一落点

- 条件/位置：canonical `_normalize_direct_target`、Controller `_resolve_direct_point_target/_point_action`、观察入口点按投影；target只要求role/meaning，tap_point合法、同帧同坐标系；typed辅助点按绑定同帧输入结构中的明确控件。
- 必要性：一个目标、一把尺子、一个点；避免本地再找中心、OCR 改点或 scene 框否决明确点。
- 影响：缺点、越界、两个目标不能执行；附带无关scene列表不能失败。label/evidence为可选说明，不因缺失或错误诊断格式否决明确目标；不要求模型知道本地输入ID。
- 结论：**已实现／限域保留**。额外 `scene.elements` 已在入口排除，不再是限制；禁止恢复。边缘手势 margin 另外归 R17，不能与屏幕越界混为一谈。
- 验证：已有原响应重放、五种点按及 typed 变化样本；具体历史测试成绩仍以主验收台账为准。

### R07 非点按及 finish 的 scene 必要事实

- 条件/位置：`_required_scene_element`、`UIElement/UIScene.validate`；drag/swipe_element等显式元素动作仍需要ID/role/meaning/bounds。文字动作绑定当前唯一输入事实，不绑定模型元素ID；finish不再解析证据路径。
- 必要性：drag/swipe_element需要明确目标几何；finish需要当前图完成说明及必要的当前输入/本次效果事实。附带引用不再使可选坏元素成为硬校验目标。
- 影响：不认识的 role、非点按选中元素错误框仍可能拒绝；没有目标不等于当前图不可观察。不能把场景类型与目标完成混为一谈。
- 结论：必要事实**有条件保留**；精确枚举属于协议适配，不证明自然语言同义词无用。点按分支不进入这些元素限制。
- 验证：非点按元素动作引用正负样本、finish不受额外路径影响、无关坏元素、低confidence样本。不能单独调用UIElement.validate的失败就声称线上仍有confidence否决，须经过正式归一化入口。

### R08 设备、会话、租约、scope 与 fingerprint 身份

- 条件/位置：device registry、跨进程 lease、session、confirmation authority、trusted observation、执行器；设备不存在、已占用、revision/observation/action digest 不一致、授权已消费时拒绝。
- 必要性：防止两个任务同时动同一机械臂、旧网页重复请求、设备切换后把旧动作发到另一手机。线程锁和跨进程锁保护不同竞争范围，不是两套任务语义。
- 影响：陈旧按钮、旧会话、重载前 scope 会失败；必须重新观察/恢复，不应要求用户重新批准普通业务效果。
- 结论：**已验证可行／保留**。同类验证可重复核对相同不可变身份，但不能分别改变 scope 内容。
- 2026-09-05 编排简化：删除独立可写的 controller_decision 会话副本及执行前“回执存在”检查。该回执始终由当前动作生成 allowed=true，不是设备能力校验；现在仅保留只读展示投影和同格式证据文件。一次性 ConfirmationAuthority、执行前当前 scope 对比及消费状态不变。
- 验证：错误设备、过期 observation、重复 nonce、并发会话；`test_device_exclusivity.py`、`test_adb_keyboard_transport.py` 及会话测试。

### R09 人工确认只针对登录和付款

- 条件/位置：`CONFIRMATION_EFFECT_KINDS`、RiskAction 派生策略、effect_gate、网页确认；authentication/financial_transaction 未有对应 scope 确认时等待。
- 必要性：这是用户明确产品决定，不来自“不可逆”或“账号影响”的泛化判断。
- 影响：发送、删除、权限变更等普通效果必须自动执行；effect kind 名称含 irreversible/sensitive 不意味着自动要求确认。
- 结论：**保留两类，禁止外扩**。内部 `confirmed=True` 与 `awaiting_confirmation` 经自动循环提交 scope，并不等于每步要人点同意；必须沿调用链判断，不能仅搜 confirmed 字样下结论。
- 验证：普通发送/清空自动推进、两类风险等待、错 scope 不可执行；已有 `test_audited_contract_conflicts.py` 的准备与效果区分。

### R10 新鲜、多帧、稳定、清晰与非占位画面

- 2026-09-08 用户批准更新：两组动态视频保存帧已离线证明动作前整图差异和机械执行门整图结构差误拦；这两道像素否决及阈值入口删除，不用放大阈值替代。接受思考期间实际跳页/目标移动可能漏拦；设备、当前 scope、尺寸、一次性凭据和机械范围仍在。公开 confirmation_frame_identity_verified=false、confirmation_frame_delta=null 明示未做像素身份证明；不是检查失败。下列多帧/清晰度和分辨率疑点没有被本例一并证明合理或不合理，R24 动作后效果保护也不在删除范围。
- 条件/位置：trusted observation、adapter capture、observation_images、camera/robot；至少四帧，选稳定末三帧中清晰帧；局部稳定阈值默认 38.0，清晰度默认 4.0，尺寸下限以及动作前图身份复核。
- 必要性：模型坐标必须对应真正可看的当前手机画面；MOCK PHONE、遮挡、过渡帧不能算证据。
- 影响：视频、光标闪烁、慢加载、横屏、低分辨率与光照变化可能误停。4、38、4.0、400×700不是数学必然；底层探测 300×500 与 adapter 400×700 还存在不同就绪口径。
- 结论：真实新图**保留**；具体阈值和竖屏尺寸假设**尚未验证**，不能把其拒绝自动归因“手机确实模糊/残缺”。fingerprint 身份保护不等于已证明当前算法对噪声鲁棒。
- 验证：同 UI 光照/闪烁、真实页面变更、横竖屏和不同分辨率成对样本；禁止为取样不断重跑手机。相机状态只读检查不能替代这些样本。

### R11 坐标系、数值范围和机械可达性

- 条件/位置：观察坐标归一化、validation、Controller、tap_calibration、seller adapter；拒绝 NaN/Inf/bool、退化框、屏幕外点、错误 frame size、奇异矩阵及不可达映射。
- 必要性：不合法数值无法形成唯一执行位置；模型 axis_grid 只转换一次，机械标定属于物理映射而非重新选择目标。
- 影响：声明坐标尺度错，即使肉眼能猜意图也不能代猜；校准覆盖不足是设备故障，不是任务风险。
- 结论：有限值/范围/非退化**保留**；校准覆盖 0.68/0.82、误差 0.02、外扩 ±0.08 等数值**有条件**，要由标定样本支持，不作全机型保证。
- 验证：四角/尺度变化、不可逆矩阵、覆盖内外、整屏比例变化；不改模型点、不做坐标补丁。

### R28 模型配置、模型身份、网络与超时

- 条件/位置：vision_model/config/provider/usage（DeepSeek provider 已退役）；配置缺失、模型身份不符、单步阶段不符、无响应/截断/HTTP失败；视觉默认 qwen3.7-plus、single-step 输出预算 5200、观察超时 60 秒。

- 结论：配置/明确模型身份**保留**；5200/60 和具体身份固定策略**有条件**。不在本次查价格、不声称当前厂商支持情况或调用成功。

### R29 用量结算与诊断不得变业务权威

- 条件/位置：vision_usage；session绑定、request事件存在、不可重复结算、计数为非负数，响应 model记录。
- 必要性：避免漏计/重复记账、看不见多次模型调用；当前账本身份门也用于阻止换模型/旧阶段。
- 影响：账本异常会抛错；其可恢复性与动作是否已执行必须由会话异常入口统一处理。价格/截断后的诊断文本不是执行授权。
- 结论：计账一致性**保留**；不得用费用估算或诊断空值阻断正常目标。来源身份保护归 R28，不另建普通动作安全门。
- 验证：重复结算、异常结算、缺 token usage、已完成事件再报错不重新执行。

### R30 能力验收、晋级与标定维护入口

- 条件/位置：capability_acceptance*、设备 verified_actions、action_acceptance/touch_calibration 页面；未登记能力不能普通运行，验收开始要求代码提交可追溯且不能 +dirty；报告/校准/registry摘要一致、一次验收一次确认、不允许重启前试验恢复执行。
- 必要性：未验证 transport 不应伪装成已实现能力；晋级改变设备能力配置，要能追溯哪套代码和标定产生证据。
- 影响：普通任务在能力表少报时可能 unsupported；dirty 阻止的是专门“能力晋级验收”入口，**不能推广成普通任务必须提交才能执行**。已有配置不等于能力在所有手机已验证。
- 结论：维护入口**限域保留**；“未验收即永不允许尝试”不是新增产品决定，应用已有受控验收流程。不能把每个任务都引到此入口。
- 2026-09-07 合同修正：能力报告与主循环共享 confirmation_authority 中唯一十字段 scope 解析器；删除非空 controller_transition_evidence 的旧要求，继续要求恰好一次实际执行、Qwen 动作后新图 previous_action_outcome=matched、前后帧/方向/标定与晋级凭据。网页候选由后端唯一 canonical→physical 映射给出，不再自行用 scroll/swipe_element 匹配物理 swipe。
- 验证：registry摘要漂移、报告已消费、历史试验只读、与普通任务互斥；不在本次晋级设备或进行标定。

### R31 证据路径、原子落盘、资源恢复和诊断裁剪

- 验证：不可读证据、错误会话 ID、路径穿越、原子替换、异常中仍释放 lease；禁止输出密钥和本地注册表内容。
