## 本批实现与反证

最初四项连接器单测只覆盖浅层队列，不能证明远程可用。实际构造曾发现 machine_position 丢失；进一步发现签名未绑定身份/查询参数、回执未绑定领取者、NaN 时间戳可通过、重复回执未核对内容、缺少本机执行记录，以及动作凭据/截图/回执不兼容。这些问题均属于本批原型缺口，未部署到公网。

修正后的链路：

1. HTTPS 出站轮询，v2 签名绑定 connector_id、完整 path/query、时间戳、随机 nonce 和正文。每个配置密钥绑定指定连接器；nonce 在 SQLite 中防重放，重启后仍有效。命令行不接收 Secret 参数。
2. 云端持久命令绑定 connector/device/command；事务领取一次；回传必须匹配归属，只有完全相同的结果才幂等。结果冲突不覆盖已记录证据。
3. 未领取超时记录 not_dispatched；已领取但无可靠结果记录 unknown。迟到结果可以保存证据，但不会把已超时步骤改为成功，也不会重新派发。
4. Windows 先持久登记再执行，结果先落盘再回传。连接中断后重传回执；已开始但未持久结果的命令在恢复时记 unknown，不重复动作。沿用现有设备及物理控制租约。
5. 远程代理保留机位、共享操作锁、捕获锁、已验证动作和单次回执接口。观察使用 PNG 无损图；平台原有一次性凭据绑定原始本机观察，交接到原物理执行门。画布尺寸变化仍按原合同失败，普通像素变化不新增否决规则。
6. 根目录 device_connector.py 只承担 CLI 启动；队列、交付记录和 worker 位于 agent/infrastructure。Runtime 仍是唯一任务生命周期权威。未配置远程设备时，不创建连接器数据库或调用连接器。
7. 网站机位按钮回归涵盖二号／十号、选择态、预览刷新、摄像头不可用但控制器在线、控制器离线与 390px 布局。
