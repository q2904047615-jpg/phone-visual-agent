范围：主方案阶段 5 的项目管理子项；暂不接入第二台真机。

## 合同与实现

网站增加“管理项目”：创建项目 ID、名称、说明和成员范围；修改名称/说明/成员；归档与恢复。归档保留历史引用，项目没有物理删除入口。项目成员范围只做组织标记，不授予任务、截图、回放、设备或模型上下文访问权；真实资源仍按用户归属隔离。

沿用现有 Control Plane `team.manage`：owner/admin 可管理本组织项目，其他角色不能写入或看到管理入口。项目读接口仍受登录、同源、组织和 `task.read` 保护。写入带 Idempotency-Key、项目 ID 绑定的请求摘要、expected_revision 乐观并发和主体审计；版本冲突返回 409，不静默覆盖。SQLite 以项目表和版本表持久化，更新和审计在同一事务内提交。
