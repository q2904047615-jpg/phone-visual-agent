# 网站权限与用户数据隔离：实施及验收台账

日期：2026-10-15。结论：**有条件可行，生产接入尚未完成**。

## 用户已确认的规则

每个用户只能访问自己的任务、回放、截图和运行上下文；管理员管理成员不代表可读取他人任务。唯一真机初始归 `local-org/local-owner`；其他用户需分配设备后使用。本机控制令牌不能用于冒充用户或签发任意主体会话。详见《用户决策与协议边界.md》0.4。

## 本批实际完成

- SQLite 新增不可覆盖的资源归属记录；组织、用户、资源类型、资源 ID、设备 ID 持久化。已有角色权限继续作为唯一角色权威。
- 提供一次性旧单用户任务归属迁移，使用事务和标记；不会在读取未知 ID 时自动认领未来任务。迁移函数尚未接入正式服务。
- 审计读取支持按当前主体过滤，过滤发生在分页前；正式读取路由尚未传入主体。
- 独立 HTTP 授权适配器检查会话撤销、角色、组织、资源所有者和设备归属；拒绝本机控制令牌充当身份、无效主体令牌回退 Cookie，以及使用旧会话签发路由冒充用户。
- 临时 ASGI 路由副本验证现有登录、退出、任务读取、回放、证据和设备请求。生产 `web_app.py` 未修改，适配器尚未启用。

## 验证结果和证据边界

从 `poc` 执行：

```powershell
.\.venv\Scripts\python.exe -X utf8 scripts/run_website_isolation_tests.py --full
```

运行器强制 Mock，导入网站时将 Runtime 数据库放在临时目录；不会监听端口、访问真实 GitHub、调用付费模型或执行手机动作。

最终日常发现回归：**951 tests，OK，skipped=4**。本地日志：`poc/output/website_isolation_regression.log`。新增 18 项测试（6 项策略与持久化、12 项路由副本与模拟身份验证）；原有官方类型化客户端测试一并通过。第一次回归的两项失败来自新增文件不符合项目目录合同、运行器改变常量影响路径断言；修正后重跑通过，没有跳过失败用例。

路由副本中本人任务读取成功；同组织管理员、其他组织用户读取该任务返回 404；匿名相机访问返回 401；未分配设备的用户访问或操作返回 403。Mock 断言确认拒绝发生在相机、控制器、任务读取调用前。模拟 GitHub 登录、退出、过期、撤销、重复回调和浏览器绑定用例通过。

这些是**离线证据**。尚未证明正式网站 Cookie 能访问所有受保护路由，未完成新权限下的真实 GitHub 登录验收，也未完成全部页面浏览器回归。历史实验测试本批未重跑；不把日常测试通过称为所有历史测试通过。

## 尚未完成和阻断原因

自动审批两次拒绝把身份校验接入全局 API，以及同步修改 Cookie、同源校验和所有权迁移，理由为可能阻断 OAuth、官方客户端、Runtime 路由和服务重载。没有通过其他路径绕过拒绝；已向用户请求明确批准“先本地接线及完整回归，通过后再重载”。当前服务未重载。

后续必须一批完成并验收：

1. 正式 HTTP 路由启用身份校验，删除公开签发任意用户会话的旧入口；迁移 Cookie 路径、兼容清理旧 Cookie，并更新官方客户端主体认证合同。
2. 任务及异步启动在执行前记录所有者；验收、监控、手动动作等资源补归属。按主体过滤设备、活动任务、验收及监控列表、审计；停止操作限于本人设备，服务重载限于本机安装所有者。
3. 实时画面与证据路径检查归属，流式响应在撤销后停止；返回数据不包含他人任务、截图或模型上下文。
4. 登录前不拉取私有数据；退出、会话过期、切换用户时清理页面和存储中的私有数据，阻止旧请求结果回填，保留清晰可用的登录入口。
5. 使用两个用户、两个组织完成 API 与浏览器正向、越权及变化样本；验证已有本人任务功能、登录、退出、官方客户端和服务重载合同。
6. 离线回归通过后才备份相关 SQLite、受控重载项目 API，核对代码版本与实际登录状态，完成已授权的零动作网站验收。不接第二台真机，不操作卖家 `main.exe`。

回滚：本批生产改动仅增加独立适配器和仓储能力，尚无正式调用；使用对应 Git commit 精确撤回，保留现有任务和用户数据。以后启用迁移前须备份数据库，不能用旧库覆盖之后产生的新任务。
