# 轻量 DDD 模块化单体

本目录只承载已经迁移并被正式运行链调用的业务切片，不用空目录或转发包装制造“看起来像 DDD”的结构。

依赖方向：

- `domain`：DeepSeek typed 任务图聚合、Qwen typed task context 与可信观察快照/候选规范化、TaskSemanticIR 与正式风险权威、通用目标只读投影/安全清洗/收件人绑定语义、canonical 动作目录/动作词汇/确定性控制器、动作后视觉上下文、视觉模型错误/配置身份、多帧稳定性与视觉遮挡证据、会话聚合、设备执行、会话证据、视觉场景、语义动作、动作能力、确定性文字事务、typed input lineage、canonical 选择回执、一次性确认作用域和已验证 App 表面血缘所需的最小合同、业务不变量和端口；不依赖 Web、PIL、模型 SDK、摄像头、文件系统或机械臂实现。
- `application`：编排 DeepSeek provider 调用与计划/重规划、Qwen 单步视觉决策和通用 Agent 一次一动作闭环，持有唯一运行会话聚合、视觉用量账本与单动作 adapter 端口/错误合同，并把输入画面描述转换为领域层消费的匹配事实；依赖 domain 端口与纯领域服务，不定义任务图或 canonical 动作，也不直接访问 FastAPI、文件系统或 infrastructure。
- `infrastructure`：实现会话仓储、本地风险策略/会话证据/输入 lineage 文件访问、DeepSeek HTTP provider 与失败诊断持久化、DashScope 视觉 provider/运行错误分类及环境配置读取、本地图像稳定性/清晰度/遮挡测量、可信观察四帧构建/新鲜度校验、单步视觉 scene observer 与单动作执行 adapter、Robot/Replay 设备执行器、跨进程租约、同设备任务注册表、每设备相机/动作协调资源和设备控制器注册表，由组合根或现有运行链注入。
- `web_app.py`：当前接口与组合根；只负责认证、Pydantic/HTTP 转换和依赖装配，并随迁移批次逐步变薄。

第一批迁移的是通用 Agent 会话生命周期；第二批迁移的是设备动作合同、Robot/Replay 执行、硬件 transport 回执和设备独占控制；第三批迁移的是会话证据端口与文件系统原子持久化；第四批迁移的是 canonical 选择回执值对象和唯一序列化合同；第五批迁移的是动作与效果确认的一次性授权作用域；第六批迁移的是已验证 App 表面血缘；第七批迁移的是通用 Agent 运行会话聚合、快照和报告版本；第八批迁移的是每设备相机串行租约与预览缓存；第九批迁移的是设备注册表、Robot/Mock 控制器构造和临时能力验收控制器；第十批迁移的是每设备动作协调锁和相机协调器实例表；第十一批迁移的是 UI 场景与语义动作领域语言；第十二批迁移的是文字规范化、字符计数与 verified input planner；第十三批迁移的是 typed input lineage 的领域记录、应用匹配端口与文件系统存储；第十四批迁移的是设备动作能力快照、稳定摘要和 typed gap；第十五批迁移的是唯一 canonical 可执行动作词汇；第十六批迁移的是 TaskSemanticIR、正式风险权威及本地风险策略文件加载；第十七批迁移的是 canonical 动作目录值对象与确定性编译服务；第十八批迁移的是通用目标只读投影与纯 JSON 对象解析；第十九批迁移的是 DeepSeek 计划/重规划应用入口与风险策略组合根注入；第二十批迁移的是 typed 任务图领域聚合、校验、builder 与确定性投影；第二十一批迁移的是视觉模型共享错误/配置身份与环境 loader；第二十二批迁移的是通用目标安全清洗与收件人绑定语义；第二十三批迁移的是 Qwen typed task context 领域合同；第二十四批迁移的是多帧稳定性/视觉遮挡证据与本地图像测量；第二十五批迁移的是可信观察领域快照、候选规范化与四帧 adapter；第二十六批迁移的是 Qwen 单步视觉决策应用入口；第二十七批迁移的是 canonical 动作确定性控制领域服务；第二十八批迁移的是单步视觉 scene observer 基础设施实现；第二十九批迁移的是单动作执行 adapter、应用端口/错误与动作后观察合同；第三十批迁移的是通用 Agent 编排应用用例、视觉用量账本和注入式 DeepSeek 失败诊断；第三十一批迁移的是 DeepSeek HTTP provider；第三十二批迁移的是 DashScope 视觉 provider 与 Qwen 运行错误分类。三十二批都已删除旧运行权威或反向依赖，不保留转发门面。
