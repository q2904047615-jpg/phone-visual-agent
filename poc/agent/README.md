# 轻量 DDD 模块化单体

本目录只承载已经迁移并被正式运行链调用的业务切片，不用空目录或转发包装制造“看起来像 DDD”的结构。

依赖方向：

- `domain`：DeepSeek typed 任务图聚合、TaskSemanticIR 与正式风险权威、通用目标只读投影/安全清洗/收件人绑定语义、canonical 动作目录与动作词汇、视觉模型错误/配置身份、会话聚合、设备执行、会话证据、视觉场景、语义动作、动作能力、确定性文字事务、typed input lineage、canonical 选择回执、一次性确认作用域和已验证 App 表面血缘所需的最小合同、业务不变量和端口；不依赖 Web、PIL、模型 SDK、摄像头、文件系统或机械臂实现。
- `application`：编排 DeepSeek provider 调用、计划/重规划与通用 Agent 用户用例、持有唯一运行会话聚合，并把输入画面描述转换为领域层消费的匹配事实；依赖 domain 端口与纯领域服务，不定义任务图或 canonical 动作，也不直接访问 FastAPI、文件系统或 infrastructure。
- `infrastructure`：实现会话仓储、本地风险策略/会话证据/输入 lineage 文件访问、视觉模型环境配置读取、Robot/Replay 设备执行器、跨进程租约、同设备任务注册表、每设备相机/动作协调资源和设备控制器注册表，由组合根或现有运行链注入。
- `web_app.py`：当前接口与组合根；只负责认证、Pydantic/HTTP 转换和依赖装配，并随迁移批次逐步变薄。

第一批迁移的是通用 Agent 会话生命周期；第二批迁移的是设备动作合同、Robot/Replay 执行、硬件 transport 回执和设备独占控制；第三批迁移的是会话证据端口与文件系统原子持久化；第四批迁移的是 canonical 选择回执值对象和唯一序列化合同；第五批迁移的是动作与效果确认的一次性授权作用域；第六批迁移的是已验证 App 表面血缘；第七批迁移的是通用 Agent 运行会话聚合、快照和报告版本；第八批迁移的是每设备相机串行租约与预览缓存；第九批迁移的是设备注册表、Robot/Mock 控制器构造和临时能力验收控制器；第十批迁移的是每设备动作协调锁和相机协调器实例表；第十一批迁移的是 UI 场景与语义动作领域语言；第十二批迁移的是文字规范化、字符计数与 verified input planner；第十三批迁移的是 typed input lineage 的领域记录、应用匹配端口与文件系统存储；第十四批迁移的是设备动作能力快照、稳定摘要和 typed gap；第十五批迁移的是唯一 canonical 可执行动作词汇；第十六批迁移的是 TaskSemanticIR、正式风险权威及本地风险策略文件加载；第十七批迁移的是 canonical 动作目录值对象与确定性编译服务；第十八批迁移的是通用目标只读投影与纯 JSON 对象解析；第十九批迁移的是 DeepSeek 计划/重规划应用入口与风险策略组合根注入；第二十批迁移的是 typed 任务图领域聚合、校验、builder 与确定性投影；第二十一批迁移的是视觉模型共享错误/配置身份与环境 loader；第二十二批迁移的是通用目标安全清洗与收件人绑定语义。二十二批都已删除旧运行权威或反向依赖，不保留转发门面。Qwen typed 上下文/决策应用用例与 Controller 仍使用现有正式模块，后续按同样方式逐批迁移。
