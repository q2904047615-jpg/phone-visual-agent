# 轻量 DDD 模块化单体

本目录只承载已经迁移并被正式运行链调用的业务切片，不用空目录或转发包装制造“看起来像 DDD”的结构。

依赖方向：

- `domain`：会话聚合、设备执行、会话证据、视觉场景、语义动作、canonical 选择回执、一次性确认作用域和已验证 App 表面血缘所需的最小合同、业务不变量和端口；不依赖 Web、模型 SDK、摄像头、文件系统或机械臂实现。
- `application`：编排一个用户用例并持有唯一运行会话聚合；依赖 domain 端口，不决定 canonical 动作，也不直接访问 FastAPI。
- `infrastructure`：实现会话仓储、文件系统证据存储、Robot/Replay 设备执行器、跨进程租约、同设备任务注册表、每设备相机/动作协调资源和设备控制器注册表，由组合根或现有运行链注入。
- `web_app.py`：当前接口与组合根；只负责认证、Pydantic/HTTP 转换和依赖装配，并随迁移批次逐步变薄。

第一批迁移的是通用 Agent 会话生命周期；第二批迁移的是设备动作合同、Robot/Replay 执行、硬件 transport 回执和设备独占控制；第三批迁移的是会话证据端口与文件系统原子持久化；第四批迁移的是 canonical 选择回执值对象和唯一序列化合同；第五批迁移的是动作与效果确认的一次性授权作用域；第六批迁移的是已验证 App 表面血缘；第七批迁移的是通用 Agent 运行会话聚合、快照和报告版本；第八批迁移的是每设备相机串行租约与预览缓存；第九批迁移的是设备注册表、Robot/Mock 控制器构造和临时能力验收控制器；第十批迁移的是每设备动作协调锁和相机协调器实例表；第十一批迁移的是 UI 场景与语义动作领域语言。十一批都已删除旧运行入口，不保留转发门面。DeepSeek、Qwen、canonical action 目录、Controller 与 typed input lineage 仍使用现有正式模块；后续只有在一个真实切片完成迁移并删除旧入口后，才继续移动下一批。
