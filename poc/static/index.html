设备分配

为组织成员分配手机。每台手机同一时间只属于一人，历史任务不会转移。

改派前请结束设备上的任务。分配不会退出手机内的 App 账号或清除手机内容。

组织成员与角色

设置谁能使用网站，以及可以执行哪些操作。

只读成员查看自己的数据；操作员可执行任务；管理员管理普通成员和设备；所有者可管理全部角色。管理权限不授予他人的任务、回放或截图访问权。

组织至少保留一名启用的所有者。停用前须先处理未结束任务；停用保留历史数据和设备归属，恢复后需重新登录。

添加成员

成员 ID 创建后不可更改。创建成员不会发送邀请；请从“管理 GitHub 关联”关联身份，再按需分配设备。

团队与成员分组

按业务或协作需要组织成员，一名成员可加入多个团队。

所有者和管理员可管理本组织团队。分组不改变角色、登录资格或设备归属，也不共享他人的任务、截图和回放。

新建团队
查看所有成员的分组

项目管理

按客户、产品或交付范围整理项目。项目归档保留历史记录，避免引用失效。

所有者和管理员可管理项目。项目成员范围只用于组织标记，不授予任务、截图、回放或设备访问权。

GitHub 身份关联

决定哪个 GitHub 账号可以登录哪位组织成员。

所有者可管理全部成员，管理员只管理操作员和只读成员。更换成员须先解除旧关联；解除会撤销该成员全部登录，但保留历史数据和设备归属，已开始的任务不会自动取消。组织必须保留一名可登录的所有者。

组织配额

查看本组织当前的运行、物理动作和模型 Token 配额。配额写入带幂等键，保存失败不会改变旧值。

运行时会按实际 Run、物理动作和模型 Token 结算；这里显示本地 CNY 估算账本，不代表云厂商最终账单。

计费账本

只显示当前组织的运行成本估算。账本按会话幂等结算，不保存令牌，也不调用支付服务。

操作审计

只显示当前组织的审计记录，按序号增量读取；敏感认证材料不会进入列表。

通知

只显示发给当前账号的组织变更通知。通知内容不包含任务正文、截图、令牌或其他账号数据。
